아이템매니아 크리에이터 디스코드 운영 기안

작성일 2026-10-19 · 마케팅팀

개요

매니아가 직접 운영하는 공식 디스코드를 게임별로 개설하고, 해당 게임으로 매니아 광고를 진행 중인 크리에이터가 방송에서 시청자를 서버로 데려와 쿠폰 이벤트에 참여시키는 구조를 운영합니다.

  • 목적: 크리에이터와 디스코드라는 신규 매체를 통해 시청자를 아이템매니아로 유입시키고, 크리에이터별 유입·쿠폰 사용 성과를 같은 기준으로 측정
  • 운영 주체: 아이템매니아 마케팅팀
  • 대상 게임: 제우스, 리니지 클래식, 리니지M, 도깨비의 세계 등
  • 서버 단위: 대상 게임별 1개 서버
  • 참여 대상: 해당 게임으로 매니아 광고 진행 중인 유튜버·인플루언서(크리에이터1, 2, 3 …)와 그 시청자
  • 쿠폰 운영: 기존에 구축한 쿠폰봇 활용(채널 단위 운영으로 일부 수정)

서버 구성

게임마다 같은 구조의 서버를 하나씩 개설합니다. 안내·거래 카테고리는 전체 공개로 동일하게 두고, 크리에이터마다 동일한 메뉴의 전용 카테고리를 만들어 해당 크리에이터 역할이 있는 사람만 볼 수 있게 합니다.

역할 체계

입장 시 선택하는 크리에이터 역할이 해당 크리에이터 카테고리의 열람 권한이 되고, 크리에이터별 유입 집계 기준이 됩니다.

운영 흐름

크리에이터 온보딩 (최초 1회)
  1. 참여 안내: 제휴 계약 시 해당 게임 서버 운영 참여 조건을 함께 안내합니다.
  2. 세팅: 해당 게임 서버에서 크리에이터에게 파트너 역할을 부여하고, 전용 카테고리(동일 메뉴)와 크리에이터 역할을 생성합니다.
  3. 자료 전달: 파트너 라운지에서 운영 가이드, 방송용 안내 문구, 배너를 전달합니다.
방송 이벤트 회차 (매 회차)
단계담당내용
1. 신청크리에이터파트너 라운지에서 방송일과 이벤트 일정 신청
2. 쿠폰 준비매니아 담당자권한자에게 크리에이터 전용 쿠폰 그룹 발급 요청 → 핀번호 파일을 쿠폰봇에 적재
3. 회차 오픈매니아 담당자해당 크리에이터 카테고리의 쿠폰 이벤트 채널에서 회차 시작
4. 방송 안내크리에이터방송 중 디스코드 링크와 참여 채널 안내
5. 참여시청자서버 입장 → 크리에이터 역할 선택 → 해당 크리에이터 카테고리의 쿠폰 이벤트 채널에서 쿠폰 수령
6. 종료쿠폰봇 / 담당자수량 소진 시 자동 종료 또는 방송 종료 시 수동 종료
7. 결과 공유매니아 담당자파트너 라운지에 회차 결과(참여 수, 지급 수) 공유

지급 방식핀번호 적재 방식. 매니아 아이디 수집 없이 디코 계정으로 중복 판별, 쿠폰번호는 본인에게만 보이게 발송
쿠폰 그룹게임별 × 크리에이터별 × 회차별로 분리 발급(예: 게임명_크리에이터1_1회차), 크리에이터별 사용 건수 측정
참여 제한회차별 디코 계정당 1회, 디코 가입 n일·서버 입장 n일 미만 참여 불가

성과 측정

게임별·크리에이터별 지표를 월 1회 파트너 라운지에 공유하고, 광고비 재협의와 신규 크리에이터 영입 근거로 활용합니다.

크리에이터 혜택: 성과 연동 인센티브

크리에이터별 쿠폰 성과에 따라 추가 인센티브를 지급해, 크리에이터가 방송에서 매니아 서버 유입을 적극적으로 안내하도록 합니다.

기준 지표(결정 필요) ① 크리에이터별 쿠폰 사용 수 또는 ② 쿠폰 사용자의 거래 금액(기존 실적 광고비 구조와 동일 방식)
지급 형태(결정 필요) ① 구간 정액(예: 월 사용 n건 이상 ○원, 2n건 이상 ○원) 또는 ② 건당 지급(예: 사용 1건당 ○원)
상한크리에이터별 월 인센티브 상한 ○원
정산 주기월 1회, 해당 월 쿠폰 유효기간 종료 후 확정
확정 조건쿠폰 그룹별 사용 내역 추출 가능 여부와 명의 기준 1회 사용 제한 적용 여부 확인 후 확정
쿠폰 사용 수를 기준으로 하면 크리에이터 측이 부계정·지인 계정으로 쿠폰을 직접 사용해 실적을 부풀릴 수 있으므로, 명의 기준 1회 사용 제한이 적용되어야 인센티브를 운영합니다.

쿠폰봇 수정 필요사항

한 봇으로 여러 게임 서버와 서버 안의 여러 크리에이터 채널을 동시에 운영합니다. 채널 단위 운영은 임시로 구현해 두었으며, 실제 테스트와 쿠폰 세부 운영 내용 확정이 필요합니다.

임시 구현 (2026-10-19)
  • 채널 단위 회차: 크리에이터 카테고리의 쿠폰 이벤트 채널마다 회차, 수량, 핀번호 파일, 방식(선착순/룰렛), 참여 조건을 따로 관리
  • 채널 단위 중복 판별: 크리에이터 채널·회차별로 참여 기록 분리, 다른 크리에이터 채널 이벤트는 따로 참여 가능
남은 작업
  • 테스트: 실제 디스코드 서버에서 크리에이터 채널별 쿠폰 지급·회차 전환 테스트
  • 쿠폰 세부 운영 내용: 채널별 쿠폰 운영 기준 확정 후 봇 설정에 반영
  • 크리에이터 역할 버튼: 입장 시 크리에이터 선택과 역할 부여(카테고리 열람 제한은 디스코드 권한 설정으로 처리)
  • 집계 명령어: 크리에이터별 유입·참여·지급 수 조회

물품등록 제목 입력 및 노출 현황 비교

아이템매니아 · 바로템 | 게임머니 / 아이템 / 계정 | 테스트일: 2026.11.11

1. 검토 목적

동일한 제목 문구를 이용해 두 플랫폼의 물품등록 제목 입력 및 화면 노출 분량을 비교하고, 제목 중심 검색 환경에서의 검색 접근성 개선 필요성을 검토하고자 함.

2. 비교 기준

• 동일 문구를 각 거래 유형에 입력하여 테스트함.
• 입력 분량과 화면에 노출되는 분량을 구분함.
• 글자 수는 공백 및 특수문자를 포함하며, 자동 접두 문구는 제목 글자 수에서 제외함.

※ 아이템매니아: 제공된 테스트에서 200자 문구 중 40자만 입력됨. 바로템: 500자 이상 입력 후에도 추가 입력 가능함. 따라서 바로템의 공식 최대 입력 한도는 미확인.

※ 바로템 화면 노출 약 88자는 제공된 캡처 기준 추정치(말줄임표 포함)로, 화면 폭·글꼴·배율에 따라 달라질 수 있음. 계정·아이템은 게임머니와 동일한 노출 방식이라는 테스트 결과를 반영함.

4. 주요 확인 사항

① 아이템매니아: 게임머니·아이템·계정 모두 테스트 문구가 40자까지만 입력되고 제목 내용 40자가 표시됨.
② 바로템: 세 유형 모두 500자 이상 입력 가능하였으며, 화면에서는 약 88자까지 표시 후 나머지가 생략되는 것으로 관찰됨.
③ 동일 테스트 조건에서 바로템의 제목 입력 및 화면 표시 분량이 더 많았음.
④ 현재 확인된 검색 방식은 물품 상세 내용이 아닌 제목을 중심으로 검색되는 방식이므로, 제목에 포함할 수 있는 검색어 범위가 중요함.

5. 검토 의견

물품 검색이 상세 내용보다 제목에 의존하는 환경에서는 제목 입력 제한으로 인해 판매자가 주요 옵션·능력치·서버명 등 검색 키워드를 충분히 기재하기 어려울 수 있음. 따라서 아이템매니아의 제목 입력 가능 글자 수 확대를 우선 검토하고, 목록·상세 화면의 노출 방식도 함께 점검할 필요가 있음. 단, 제목 전체가 검색 색인에 반영되는지와 상세 내용의 검색 제외 여부는 검색 테스트 및 담당 부서 확인을 통해 최종 검증해야 함.

6. 기대 효과 및 후속 확인

• 판매자가 물품의 주요 정보 및 검색 키워드를 제목에 더 충분히 기재할 수 있음.
• 구매자의 다양한 검색어에 대한 물품 발견 가능성 개선 기대.
• 후속 확인: 제목 전체 검색 반영 여부, 상세 내용 검색 여부, 제목 최대 입력 한도, 모바일·PC 노출 차이 검증.

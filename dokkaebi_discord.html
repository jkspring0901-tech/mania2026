1. 추진 목적

이용자가 많고 활성화된 게임 커뮤니티 디스코드에 서버 관리 지원을 제공하고, 그 대가로 아이템매니아 홍보 및 상품 노출을 확보하는 디스코드 광고상품을 개발하고자 함.

첫 대상은 카카오게임즈 신작 MMORPG 도깨비의세계(2026.10.08 정식 출시)의 커뮤니티 디스코드로, 유저·유튜버가 개설한 커뮤니티 서버를 대상으로 하며 게임사 공식 서버는 제외함.

  • 공통: 3곳 모두 서버 부스트, 거래소 채널, 카카오톡 오픈톡 운영 중
  • 규모: ③이 멤버 수(1,671명)와 부스트 레벨(3레벨) 모두 가장 높음
  • 활동량: ① > ② > ③ 순. 신규 게임이고 모바일과 병행하는 게임 특성상 3곳 모두 디스코드 활동량은 전반적으로 저조함 (③은 멤버 수 최대이나 활동량은 가장 낮음)
  • ①·③: 서버 전용 봇이 없어 봇 제공형 관리 지원 적용 가능
  • ②: 자체 관리BOT을 운영 중으로, 지원봇 제공 시 기능 중복 가능
3곳 모두 운영 주체는 사설 관리로 추정되나 확인 필요. 운영자 유형(유튜버·스트리머 여부)은 미조사 상태로, 대상 서버 우선순위 확정 시 추가 확인 필요.

지원봇 깨비봇 (기제작)
  • 거래소 티켓: 아이템·재화 판매 등록, 판매글 모아보기, 1:1 거래방, 거래 완료·문의 종료·신고, 거래 로그 저장
  • 문의·신고 티켓: 문의·신고·버그 제보·제휴 문의, 1:1 운영진 채널
  • 신규 가입자 환영 인사
  • 데이터 자동 백업·복원, 로그 90일 경과분 자동 삭제
  • 현재 기본 기능 중심 버전으로, 서버 운영자 요청 시 기능 추가 개발 지원

지원봇에는 광고를 넣지 않고 서버 운영 지원 용도로만 제공하며, 아이템매니아 노출은 홍보봇을 통해 확보함.

광고비 없는 상호 교환 방식으로 진행하며, 공동 이벤트 경품으로 서버 혜택을 보강함. (서버 운영자의 광고비 요청 시 별도 협의)

상품 구성

구성아이템매니아 제공확보 노출

홍보봇 (아이템매니아 봇) 매물 알림, /매물검색 서버 내 아이템매니아 매물 노출 및 링크 유입
공동 이벤트 서버 이벤트 기획·운영 지원, 경품(아이템매니아 마일리지·쿠폰) 제공 "아이템매니아 × 서버" 제휴 공지 및 이벤트 노출
· 홍보봇 노출 매물은 매물마다 주소가 달라, 어떤 매물을 클릭하든 디스코드 유입으로 하나의 카운터에 집계되도록 하는 기능은 현재 미구현 (구현 방법 검토 중).
· 깨비봇은 현재 특정 서버 하나에 맞춰 채널·역할 설정이 고정되어 있어, 여러 서버에 제공하려면 서버별 설정 분리를 위한 코드 수정이 필요함 (진행 승인 시 개발 기간 확보 필요).
· 깨비봇의 공식 포럼 자동 공지 기능은 게임사 포럼 API의 접속 차단을 우회하는 방식으로 동작하여, 아이템매니아 제공 버전에서는 제외함 (필요 시 법무팀 검토 후 추가 검토).

5. 기대 효과

  • 도깨비의세계 커뮤니티 이용자 대상 아이템매니아 브랜드 노출
  • 커뮤니티 거래소 채널의 거래 수요를 아이템매니아 거래로 유입
  • 디스코드 커뮤니티 대상 광고상품 운영 모델 확보 (타 게임 커뮤니티 확장 기반)

6. 결론 및 요청사항

도깨비의세계 커뮤니티 디스코드를 대상으로 지원봇(깨비봇) 무상 제공과 홍보봇(아이템매니아 봇) 노출을 교환하는 제휴 모델을 시범 운영하고자 함.

첫 대상은 활동량 1위이며 전용 봇이 없는 ① 도깨비의 세계로 하고, 성과 확인 후 ③, ② 순으로 확대 및 타 게임 커뮤니티 확장을 검토하고자 함.

  • 코드 수정 개발 기간 확보

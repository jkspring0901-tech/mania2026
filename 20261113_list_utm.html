배경

  • 디스코드 매물노출 봇의 「매물 보러가기」 링크는 매물마다 주소(매물번호)가 달라, 고정 주소 기준으로 집계되는 카운터링크로는 측정이 되지 않습니다.
  • 이에 링크에 UTM을 붙여 GA에서 유입 성과를 측정하는 방향으로 진행하고자 합니다.

깨비지지 제휴 성과 측정 방안 (총 3가지)

디스코드 제휴 매크로카운터링크 + UTM
디스코드 매물 노출UTM (GA) — 이번 적용 대상
깨비지지 사이트 배너카운터링크 + UTM

적용 방법

1. 봇 코드 수정봇이 「매물 보러가기」 링크를 만드는 부분에 UTM이 자동으로 붙도록 코딩
2. 게임별 값 설정게임별 봇마다 campaign 값을 지정 (예: 도깨비의세계 → dokkaebi_trade)
3. 봇 재시작 · 적용수정한 코드로 봇을 재시작하면, 이후 노출되는 매물 링크에 UTM이 자동으로 적용

동작 흐름

1현재 매물노출 기능

게임별 디스코드 채널에 신규 매물이 노출되고, 「매물 보러가기」 링크로 이동합니다.

2링크 클릭 시 이동 주소

기존 매물 주소 뒤에 UTM(빨간 박스)이 자동으로 붙은 링크로 이동합니다.

3랜딩된 매물 페이지

UTM(빨간 박스)이 붙은 상태로 매물 페이지에 랜딩되어, GA에서 디스코드 봇 유입으로 집계됩니다.
